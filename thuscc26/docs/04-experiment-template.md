# 实验记录模板

每次复制为单独Markdown记录；尚未运行填“计划”，不能把候选参数写成已验证成果。公开记录写摘要，完整原始日志留在本地。

| 项目 | 填写内容 |
|---|---|
| 实验名 / 日期 / 状态 | 计划、已提交、运行中、已完成、失败 |
| 问题与假设 | 预计哪种开销会减少，为什么 |
| 唯一改变 / 固定条件 | 对比哪个baseline，保持哪些因素不变 |
| 配置 / Git提交 | HPL.dat、编译与运行脚本的版本 |
| 二进制与环境 | SHA-256、编译器、BLAS/MPI、实际链接 |
| 资源 | 节点数、CPU、MPI进程、线程、绑定、节点类型 |
| N / NB / P / Q | 完整参数 |
| 作业号 / Slurm状态 | 核对sacct的退出状态 |
| PASSED / 残差 / 失败与跳过数 | 正确性未通过则不参与性能比较 |
| 求解秒数 / GFlop/s | 读取HPL结果表 |
| 重复测量与波动 | 原样记录各次结果；不足时注明待复测 |
| 原始证据 | 本地完整日志和配置的位置；是否已备份 |
| 结论 / 下一步 | 支持、否定或不足以判断假设 |

公开前去除账号、地址、内部路径等信息；**不能编辑原始计分日志来脱敏后提交**。本模板是单独摘要，不替代原始证据，也不代表已完成计分提交。
